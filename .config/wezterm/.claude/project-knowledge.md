# WezTerm設定 プロジェクト知見

## 概要
このファイルはWezTerm設定に関する実装パターン、設計決定、避けるべきパターンを記録します。

---

## キーバインド設定

### 重要な前提条件

**現在の設定方針**: `wezterm.lua` で `config.disable_default_key_bindings = true` を設定し、デフォルトキーバインドを完全に無効化している。

これにより、すべてのキーバインドは `keybinds.lua` で明示的に定義する必要がある。

### 実装パターン

#### 1. 新しいキーバインドの追加

新しいキーバインドが必要な場合は、必ず `keybinds.lua` に明示的に追加すること。

```lua
-- keybinds.lua への追加例
{ key = "Enter", mods = "SHIFT", action = act.SendString("\n") },
```

#### 2. IME関連の考慮事項

`config.macos_forward_to_ime_modifier_mask = "SHIFT|CTRL"` が設定されているため、Shift修飾子やCtrl修飾子を使用するキーバインドはIMEに転送される可能性がある。

日本語入力時の動作も考慮してキーバインドを設計すること。

### 避けるべきパターン（アンチパターン）

1. **「WezTermでは標準で動作するはず」という前提での開発**
   - 公式ドキュメントで「デフォルトで対応」と記載されている機能も、このプロジェクトでは明示的な設定が必要

2. **`keybinds.lua` への追加なしで新機能を期待すること**
   - デフォルトキーバインドが無効化されているため、必ず明示的な定義が必要

### 過去の問題と解決策

#### Shift+Enterが改行として動作しない問題（2026-02-01）

- **問題**: Claude CodeでShift+Enterを押しても改行が入力されなかった
- **原因**: デフォルトキーバインドが無効化されており、Shift+Enterの明示的な定義がなかった
- **解決**: `keybinds.lua` に以下を追加
  ```lua
  { key = "Enter", mods = "SHIFT", action = act.SendString("\n") },
  ```
